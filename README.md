# AI COMIC – projekt Next.js (NIEPRZETESTOWANY, nieuruchamiany)
1. Supabase: SQL Editor → wklej schema.sql. Auth → włącz logowanie e-mailem (magic link); w URL Configuration dodaj adres swojej strony.
2. Skopiuj .env.example → .env.local i uzupełnij. Bez GEMINI_API_KEY działa tryb DEMO (szablony).
3. `npm install` → `npm run dev` → http://localhost:3000
4. Wdrożenie: GitHub → Vercel (wklej zmienne środowiskowe) → Deploy.
Nie zrobione: usuwanie konta, panel admina, podłączenie obrazów AI do UI (endpoint /api/scene-image jest), regulamin/polityka prywatności.
